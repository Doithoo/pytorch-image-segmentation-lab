# VOC 2012

[中文](voc2012.zh-CN.md) | [Dataset formats](dataset-formats.md) | [Documentation](../README.md)

Extract VOC 2012 so `data/raw/VOCdevkit/VOC2012` contains `JPEGImages`, `SegmentationClass`,
and `ImageSets/Segmentation`. Then run:

```bash
uv run segment prepare-data --config configs/voc2012.yaml
uv run segment inspect-data --config configs/voc2012.yaml --split train --limit 16
uv run segment train --config configs/voc2012.yaml --dry-run
```

The provider writes the canonical 21-class schema and ignores mask value 255. VOC 2012 has no
public labeled test masks; the example config uses `test_policy: use_valid`, so evaluation called
"test" is still validation data and must be reported as such. Supply an explicit labeled test list
for a separate evaluation split. No download or benchmark result is claimed by this guide.
