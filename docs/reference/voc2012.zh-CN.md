# 使用 VOC 2012

[English](voc2012.md) | [数据集格式](dataset-formats.zh-CN.md) | [文档导航](../README.zh-CN.md)

解压后确认 `data/raw/VOCdevkit/VOC2012` 下有 `JPEGImages`、`SegmentationClass` 和
`ImageSets/Segmentation`，再运行：

```bash
uv run segment prepare-data --config configs/voc2012.yaml
uv run segment inspect-data --config configs/voc2012.yaml --split train --limit 16
uv run segment train --config configs/voc2012.yaml --dry-run
```

provider 会写入标准 21 类标签模式，并忽略掩码值 255。VOC 2012 没有公开的带标签测试
掩码；示例配置使用 `test_policy: use_valid`，因此名为 test 的评测仍是验证集，报告时需要
明确说明。若有独立带标签数据，应通过 `test_list` 指定。本文不声称完成了下载或基准训练。
