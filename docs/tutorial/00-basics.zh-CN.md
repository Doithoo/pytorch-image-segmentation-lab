# 教程 00：分割基础

[English](00-basics.md) | [教程索引](../learning-path.zh-CN.md)

本章建立后续所有内容使用的张量词汇。

## 分类与分割

图像分类为每张图返回一个类别；语义分割为每个像素返回一个类别。一批 RGB 图像是
`[B,3,H,W]`，二类分割 logits 是 `[B,2,H,W]`，整数目标和预测是 `[B,H,W]`。

单个像素的两个 logits 是背景和宠物的未归一化分数。交叉熵内部应用 softmax。只有
为指标或输出作出类别决定时，才使用 `argmax(dim=1)`。

## 运行形状示例

```bash
uv run python examples/01_mask_and_logits.py
```

在文件中找到原始掩码、映射目标、logits 和预测。解释为什么目标没有通道维度，以及
为什么损失前不能把 logits 彩色化。

## 掩码是数据

掩码像素是整数类别，不是亮度。双线性缩放可能产生 1.4 等不存在的类别，因此掩码
使用最近邻插值，并与视觉颜色分开保存。

Oxford 原始标签 3 表示未分类并映射为 255。忽略它表示项目不判断其类别，不代表
模型学习第三个类别。
